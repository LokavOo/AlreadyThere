# AIME 2026 试跑（程序 v2.10.0，2026-10-21）/ AIME 2026 trial runs

- `测试总结.md`：三次运行的事实汇总（只记录账本与运行日志里的事实，不做推断）。
- `A11`、`A12-A13`、`A14-A15`：每次运行一个文件夹——`config.json`（题目、口径、标准答案）、`settings.snapshot.json`（角色、模型、参数；不含密钥，只有密钥的名称）、`结论.md` / `结论.json`（当时版本生成的结论）。账本数据库（含各模型的完整思考和回答）未公开。
- 第三次运行（A14、A15）由用户中途停止，没有走完流程。
